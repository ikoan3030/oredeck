# docs/

設計文書を置く場所です。実装を始める前に、該当する文書をここで確認してください。

## 配置予定の文書

- **企画書** — 何を作るのか、なぜこの体験なのか
- **プロトタイプ仕様書** — 決定表、信頼度、介入、対戦の確定仕様

## 位置づけ

設計判断はチャット側で行い、その結果がここに文書として残ります。**実装は文書に従い、文書に書かれていないことを勝手に決めないでください。**

文書と実装が食い違っている場合、どちらが正しいかを実装側で判断しないこと。食い違いを報告して、確認を取ってから進めてください。

開発ルールは [../AGENTS.md](../AGENTS.md) にあります。
