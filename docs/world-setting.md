# 世界観設定資料 v2.0 ── 悪の組織と2周目構想

企画書v0.3 §2(世界観・トーン)の拡張。台詞執筆・キャラ演出・2周目実装の際に参照する設定の正本。実装仕様ではない。

v1.0からの改訂: 組織のトーンを「悲哀の清算」から「幸福の最中」へ全面修正。動機を三層構造で再定義。2周目の完全な絵図(敗北→逃走→声援→エキシビジョン)を追加。

## 1. 基本世界(企画書からの再掲+補強)

- 平成カードゲームアニメの質感。時代設定は明示せず「アニメの中の街」として普遍化
- 世界はカードを中心に回っており、カードの力を引き出せるのは子供だけ。大人になると力が失われる
- **力は子供に宿るのではなく、子供とカードの「間」に生まれる**(シンクロ率の世界観的根拠)
- **力は使い切ることで手放される。** 子供時代を燃やし尽くした者は満足とともに力を失う。喪失は成長の証
- プレイヤー=兄ちゃんは引退した元・強いカードバトラー。華やかな子供時代を過ごし、やり切って、次に渡す番が来た。過去を懐かしむ振る舞いは一切しない(明言せず、振る舞いだけで伝える)

## 2. 旧組織(かつての本物の悪)

- **本気の悪の組織。** カードバトラーの力を奪い、兵器として軍事転用しようとした。擁護の余地のない悪
- 力の簒奪は徹底的で、被害者は力を搾り尽くされ、二度とカードバトルができなくなる——子供とカードの「間」そのものを切断する行為
- プレイヤー(兄ちゃん)が子供の頃に、仲間とともに打倒した。テレビ中継され、当時の子供たちが目を輝かせて見ていた
- **作中ではほぼ描かない。** 名前と「かつて実在し、倒された」という事実だけを置く
- 名前は未決。条件: 禍々しく、古風で、大仰。「新生/ネオ」を冠した時に間が抜けること。候補: デス・アルカディア / 覇道十字軍 / ゼクスヴァール機関 / 黒晶結社 / グラン・ドミニオン / アドラス財団

## 3. 新組織(本作の敵)──「新生◯◯」

### 動機の三層構造

| 層 | 内容 | 誰が知っているか |
|---|---|---|
| お題目 | 世界征服 | 全員が掲げている |
| 目的 | **満たされなかった青春の再演と継続** | ボスだけが理解している |
| 本音 | **完全燃焼** | 本人たちも自覚していない |

### 組織の現在: 幸福の最中

- 彼らは**今、人生でいちばん楽しい**。悪の組織を演じることで、カードバトルができなかった過去を慰めており、その装置は機能している
- 哀れな者たちの物語ではない。楽しくやっている大人たちが、最後に大人としてちゃんと負ける物語である
- 力を奪うのは野望のためではなく、**「今の楽しい時間を終わらせたくないから」**。動機の根は悲哀ではなく現在の幸福の防衛にある

### 構成員の共通項

- 全員が、旧組織とプレイヤーの戦いを**テレビ越しに見て目を輝かせていた**世代。「自分もあの場所にいたかった」——熱い物語に参加したかった
- その願いは**今、叶っている**。悪役側という形ではあるが、彼らは物語の中にいる。名乗りを上げ、全力で戦い、吹き飛ばされる——あの日画面の中で見た「熱い物語」そのもの
- **無自覚の満足。** 自分が幸福であることに気づいていない。気づいたら再演が終わってしまうから

### 後継の自称

- 旧組織の名前に「新生」「ネオ」を冠して名乗るが、**実際の繋がりは一切ない。名乗っているだけ**
- 自分の物語を持てなかった者たちが、憧れた物語の続きを、配役を変えて再演している

### 力の簒奪(新組織版)

- ボス由来の機械で子供から力を奪うが、奪い方が中途半端。被害者は2〜3日寝込む程度に体調を崩し、しばらくシンクロ率が上がりにくくなる(テンションが上がらない)が、やがて戻る
- **被害を受けた子供たち自身も、意外に気にしていない。** 数日寝込んで、ちょっと乗らなくて、まあそんなもんか、くらいの受け止め。誰も本気で傷ついていない世界
- 関係を弱らせるが、断たない。旧組織(関係の切断)との決定的な違い

### 手加減の共犯構造

- 手加減しているのはボスの機械であって、末端の意志ではない。だから末端は「自分は本気だ」と言い張れる
- 末端は薄々手加減に気づいているが、**口に出すのは無粋だと思っている**。誰かが指摘した瞬間に熱狂が終わるから、言わない。大人だから、そういう配慮ができてしまう
- **この構造は台詞で表現しない。** 表現できるのは「間」のみ。言語化は2周目まで封印

### トーンの配合

- 主成分は**賑やかな楽しさと滑稽さ**。凝った衣装、大仰な決めポーズ、長すぎる名乗り口上を、大人が大真面目に、心から楽しんでやっている
- 切なさは背景に薄く敷くだけ。前面に出さない。彼らは幸福なので、可哀想という視線がそもそも成立しない
- 大人は必死に危険な悪を演じ、子供は危険と思っていない——この温度差が賑やかさの源泉

## 4. ボス(首領)

- 抑圧された子供時代を過ごし、類まれなカードバトラーの才能を持ちながら、それを活かす機会が一度もなかった。**使わなかったから、失わずに済んだ**——大人になっても不完全な形で力が残っている
- 抑圧の中身(家庭・病気・環境)は**明言しない**。「機会がなかった」という事実だけ置く
- 他者に力を分け与えられるほど強い。独裁ではなく**分配**——自分と同じ「出し切れなかった者たち」を見捨てられない。組織は結社というより共同体
- 兄ちゃんを一方的に知っている。テレビ画面越しに見ていた、旧組織と戦う本物の主人公。憧れであり「自分がなれたはずの姿」。兄ちゃんはボスを知らない
- **組織で唯一、目的(青春の再演と継続)を自覚している。** この遊びが何であり、永遠ではないことを、彼だけが知っている
- だからこそ最後に、大人として、倒されるべき敵としての自覚をもって敗北を受け入れ、組織全員分の青春を代表して清算する。楽しい時間を始めた者が、終わらせる役目も引き受ける——これは悲哀ではなく**責任**の物語
- 彼らは全員、本懐を遂げる。**これはハッピーエンドである**

## 5. 情報開示の設計(周回構造)

### 1周目: 額面通りの少年漫画

- 子供たちが悪の組織を打倒するシンプルな物語。三層構造の下二層・手加減・憧憬の一切を見せない(兄ちゃん=プレイヤーにも見せない)
- 台詞は様式通りの悪役文句のみ。二重の意味を仕込む必要はない
- クリア後に一行だけ、2周目への扉を示唆する。**1周目に謎を置くのではなく、2周目の入口に変化を置く**

### 冒頭の説教(確定・最重要の伏線)

序盤も序盤、おそらく1周目の導入部に、友達と喧嘩した弟をプレイヤー(兄ちゃん)が叱るシーンを置く。喧嘩の理由はカードバトル絡みでも何でもよい。

> **「友達を大切にしない奴にカードは応えてくれないぞ」**

**二重に効く:**

- **表(1周目):** シンクロ率の仕組みそのものの実演。弟妹が兄の言葉に耳を傾け、好みを汲まれ、噛み合っていく——人との関係が力に変わる様を、プレイヤーは梯子を上りながら実際に見る
- **裏(2周目):** ボスが真ラスボス戦でシンクロを得る原理の先出し。子供の条件を満たせない大人が、**仲間との間に生まれたもの**で同じ場所に辿り着く。1周目では説教、2周目ではルールの説明になる

**この台詞が兄ちゃんの口から出ることの意味:** 力を失い自分では戦えない彼が知っている唯一の真理が、最後に敵を救う原理になる。兄ちゃんとボスは面識がなく最後まで交わらないが、**同じ法則の上で戦う**。ボスは知らないうちに、憧れた人の教えを実践して力を得ている。

**演出上の鉄則:**

- **名言に見えてはいけない。** 子供への説教として普遍的で、ちょっと古臭く、少し押し付けがましい、いかにも兄が言いそうな言葉であること。格言めいた提示をした瞬間にプレイヤーが身構え、伏線が露見する。喧嘩の状況を具体化し、感情の流れの中で自然に出す
- **2周目で明示的に回収しない。** ボスがシンクロする場面で誰かに「そういえば兄ちゃんが言っていた」と言わせたら台無し。プレイヤーが自分で気づくのが唯一の正解で、気づかない人がいても構わない

### 2周目: 開示と真ラスボス戦

開示されるのは「悲しい真相」ではなく、**彼らがずっと幸福だったことの開示**である。

**絵図(確定):**

1. **ラスボス戦(1戦目)。** 弟妹が勝利する。この敗北により、組織を維持するための「奪う力」は失われる——楽しい時間の終わりが確定する
2. **ボスの逃走。** 唯一の自覚者である彼が、自覚していながら**未練で逃げる**。自分がいなくなれば、仲間たちの青春も終わってしまう。責任と未練の両方を持つのが大人であり、未練が勝つ瞬間があるのも大人である。かっこよくない逃走があるから、最後の戦いがかっこよくなる
3. **通信。** 逃げた先で追い詰められたボスに、どこからともなく通信装置越しに、仲間たちの声が届く——満足と、ボスへの感謝
4. **幹部の理解。** 幹部たちは分かっていた。この時間が永遠ではないこと。先の敗北で、組織を維持する力は既に失われたこと。**それを全部受け入れた上で**、彼らは告げる——**「勝ってくれ」**。終わりを受け入れた者だけが言える声援。慰めでも引き止めでもない
5. **シンクロ。** 仲間の声援を受けて、ボスとカードがシンクロする。子供の条件(子供とカードの間)を満たせない大人が、**仲間との間に生まれたもの**をカードに流し込む別経路で、同じ場所に辿り着く。「真の仲間と真のカードバトラーの力」
6. **真ラスボス戦。** 分配する側だったボスが、最後に仲間から受け取って戦う

**エキシビジョンマッチである(最重要):**

- この試合の勝敗はエンディングに影響しない。どう転んでも組織の結末は変わらない
- 利害が完全に取り除かれた試合——世界の命運も組織の存続も賭かっていない。残っているのは「全力で戦いたい」だけ
- つまりこれは、ボスが子供の頃に一度もできなかった、**何も賭かっていない、ただ楽しいだけのカードバトル**そのものである。彼が生涯欲しかったものの正体が、最終戦の形式そのものになっている
- **影響しないからこそ熱い。** 勝てたら嬉しい高難度チャレンジとして、やり込みの置き場所に収まる
- 2周目でも子供たちは何も理解しないまま全力で殴りに行く(「まだやるの!? つよ〜い!」)。モノローグと通信の意味は兄ちゃん=プレイヤーにだけ届く

### ボス側シンクロ(実装は後回し、保留理由は一部解消)

- 上昇トリガー: 被ダメージ案(追い詰められるほど噛み合う)、または声援演出と連動した時間経過
- エンジンは既存の恒常ボーナス機構(opponents.jsonへのボーナス表追加)で対応可能
- 旧保留理由「バランス調整が難しい」は、エキシビジョン化により**大幅に軽減**——勝敗が結果に影響しないため、多少理不尽に強くても壊れない。ただし実装順は変わらず1周目完成後

## 6. ゲーム構造との対応表

| 世界観 | メカニクス |
|---|---|
| 力は子供とカードの「間」に生まれる | シンクロ率 |
| 出し切ることで力を手放す | 兄ちゃんの引退(プレイ不能)、周回の区切り |
| 組織の力は「使い残し」の分配 | 敵はシンクロ(成長)を持たず、素の数値で強い |
| 絆が格上に届く | シンクロによる後半の敵アッパーの正当化 |
| 仲間との間に生まれるもの | 真ラスボス戦のボス側シンクロ(別経路の同着) |
| 憧れの再演 | 弟妹の梯子が「かつて兄ちゃんが戦った物語」の反復 |
| 何も賭かっていない試合こそ楽しい | 真ラスボス戦のエキシビジョン設計 |
| 冒頭の説教「友達を大切にしない奴にカードは応えてくれない」 | シンクロ率の原理そのもの。1周目は実演、2周目はボスの覚醒条件として回収(明示せず) |
