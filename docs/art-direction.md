# アートディレクション方針書 v1.0

「兄ちゃん！俺のデッキ作って！（仮）」のグラフィック全体方針。生成AI活用を前提とし、AIっぽさ（統計的中心への収束）を構造的に回避する指定として機能させる。

---

## 1. 基本方針

| 項目 | 決定 |
|---|---|
| 画風 | **コロコロ系少年漫画**（90年代〜2000年代児童漫画）。太い主線、ベタ塗り、強いデフォルメ、誇張された表情 |
| 質感 | **GBA〜DS期の高粒度ドットグラフィック**（3Dモデリング以前の、粒度の細かいドット絵） |
| 例外 | **カードイラストのみ美麗イラスト調を許容**（後述） |

### 選定理由

- 「AIっぽさ」は指定の不在に宿る。平均的美麗イラストは生成モデルの統計的中心であり、コロコロ系はその対極（太線・ベタ・デフォルメ）に位置する
- 平成カードゲームアニメ文化の出自がコロコロ誌面文化そのもの。世界観・トーン・UI方針（効果線とフォントの太さで殴る）と同一方向
- GBA/DS期ドットは、コロコロ系画風をゲーム画面に落とす歴史的な標準手法だった。画風と表現手法が元々セット
- 太い線とベタ塗りは減色・低解像度化に耐える。生成物の加工が効く
- デフォルメの強いキャラは記号性が高く、生成AIでの同一性維持が容易

## 2. カードイラストの例外規定

カードイラストのみ、イラスト調（美麗方向）を許容する。

- 根拠: カードは作中世界でも「絵が描かれた工芸品」であり、画面の画風から独立した一段別のレイヤーにある。参考: デュエル・マスターズのカードイラストは画風が統一されておらず、それが世界の豊かさとして機能していた
- 効果: ドットの世界の中でカードだけリッチであることが、「カードが特別なものである」という世界観（カードを中心に世界が回る）を質感差で表現する
- 運用: カード枚数（40〜100枚）は生成→機械的な減色・調整で量産。立ち絵・カットイン等の少数で目立つ素材は手加工（輪郭打ち直し・パレット統一）を入れる

## 3. 生成時の指定原則

- 特定作品名・作家名をプロンプトに入れない。特徴の記述で指定する（「太い主線、ベタ塗り、強いデフォルメ、誇張された表情、90年代〜2000年代の児童漫画風」等）
- 「描かないもの」を明示する（繊細なグラデーション、細密な陰影、リアル頭身等）
- 美麗イラストをドット化する場合も、生成段階からドット化前提の絵柄（太線・ベタ・少色数・明快なシルエット）で出す。「低解像度化された絵」と「低解像度で描かれた絵」は別物であり、美麗画の単純縮小は必ず破綻する

## 4. 素材別の調達方針

| 素材 | 手法 | 備考 |
|---|---|---|
| キャラ立ち絵（4体） | PixelLab で試作→判定 | まず単純弟1体で画風・同一性・出力サイズを検証 |
| カードイラスト | 生成（イラスト調可）→機械加工 | 枚数勝負。1枚あたりの加工コストを抑える |
| カットイン | シルエット＋効果線＋文字（CSS）を主体、絵は補助 | ドットの顔アップは密度不足が目立つため、構図と勢いで持たせる平成アニメの様式に従う |
| UI・演出 | コード/CSS（生成AI不使用） | 質感の主戦場。帯の角度、フォントの太さ、集中線、画面の止め方 |
| ストア素材 | 立ち絵確定後に着手 | カプセル画像に弟の顔と吹き出しを載せる（「何のゲームか一目で分かる」の最優先処方）|

## 5. Steam上の開示

AI生成コンテンツの使用はストアページで開示する（Steam規約上の義務）。隠さず、個人開発の制作体制として堂々と記載する。

## 6. 未決事項

- 4キャラのデザイン記号（髪型・色・特徴）の文章定義 — 生成指定の元になる。世界観の未決（4人の関係性）と合わせて詰める
- PixelLab 試作の判定基準クリア可否（画風再現・同一性・サイズ）
- カード用イラストのパレット・トーン統一ルールの具体化
