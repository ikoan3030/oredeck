企画書v0.3準拠。検証対象は「受動介入で好みと構造の二者択一を十数回問われることが面白いか」の一点。

## 1. 美的タグと重み

全キャラ共通で4語固定。値は0〜3。エンジンは重み表を引くだけなので7語鉄則の対象外とする。

| タグ | 記号 |
|---|---|
| かっこいい | C |
| かわいい | K |
| クール | cool |
| 派手 | H |

**4語は4キャラに一対一で対応する。** 単純弟＝かっこいい／気弱妹＝かわいい／いとこ＝派手／聡明弟＝クール。旧案の「シブい」はどのキャラの第一選好でもなく、いとこに対応する語も欠けていたため差し替えた。

**美的スコア = Σ(タグ値 × キャラ重み)**

**単純弟の重み：** C×1.0 / H×0.7 / cool×0.3 / K×0.0
**一目惚れ閾値：** 2.4

閾値到達の組み合わせ例：C3=3.0 ／ C2,H1=2.7 ／ C1,H2=2.4 ／ C2,H2=3.4

**プール設計上の鉄則：意図しない一目惚れを防ぐため、有用札の美的スコアは2.4未満に抑える。** 具体的にはC2までとし、Hを併せ持たせない（C2,B1=2.3は可）。強い札に最高美的値を与えないことが相関崩しの操作点そのものである。

## 2. 単純弟の決定表（確定形）

```
【前処理】一目惚れ判定
  提示2枚それぞれの美的スコアを算出
  閾値2.4以上のカードが存在する場合:
    → 無条件に選択
    → 両方が閾値以上ならスコアの高い方
    → 受動介入は発生しない
    → 以後いかなる介入手段でもデッキから除去できない

【通常処理】逐次比較（上から順に適用、決着時点で停止）
  ① モンスターを優先
  ② コストが低い方
  ③ 攻撃力が高い方
  ④ 美的スコアが高い方
  ⑤ 提示順が先の方（完全同点の最終決着）

【受動介入】
  決着後、確率50%で兄に意見を求める
  第一希望＝決定表の結論
  ※一目惚れ発火時は抑制（上記）

【信頼度変動】
  変動幅 = キャラ係数 × 却下されたカードの美的スコア係数
```

**②コストを③攻撃力の上に置く理由（v2で変更）。** アグロ選好である以上、単純弟は安い札から取るのが自然。加えて実測上の効果が大きく、攻撃力優先だった旧版では欠損数が平均3.44個（全項目が同時に不足しカバー不能）だったものが、コスト優先で2.03個に減り、診断が成立する水準になった。攻撃力を上に置くと「打点が高い＝重い札」を無条件に掴み続け、カーブ・耐久・除去がすべて同時に壊れる。

**①モンスター優先は必須である。** コスト優先にすると1コストスペルが最安値で勝ってしまうため、①がないとデッキがスペルだらけになる。※旧版（攻撃力優先）ではスペルの攻撃力が0のため②で必ず負け、①は冗長だった。順序変更により意味を取り戻した段である。

**④の位置は意図的な隔離である。** ①②③で決着しなかった場合にしか読まれないため、美的スコアは実質的に一目惚れ専用の値になる。実装時にバグと誤認しないこと。

**体力は決定表で一切参照しない。** 単純弟が体力を軽視するという設定は、決定表ではなくカードプール側（かっこいい札の体力を低く設計する）で表現する。④に「体力が低い方」を追加する案を実測したが、タイブレークまで到達する頻度が低く結果はほぼ不変だった（モンスター平均体力3.19で同値）。

## 3.5 プロトタイプの確定パラメータ

| 項目 | 値 | 根拠 |
|---|---|---|
| ピック回数（デッキ枚数） | **15** | 20ピックで一目惚れ3.7回、30ピックで5.6回と増えすぎる。15で2.8回と目標帯 |
| 同一カード上限 | **2枚** | バランス上はほぼ無影響（上限1/2/3/無制限で欠損数1.84〜2.02）。演出面で決定してよい |
| 提示 | 2択・重複あり | 上限到達カードは提示対象から除外 |
| 受動介入 | 確率50%（一目惚れ時は抑制） | 実測で1周あたり約6回発生 |

### 信頼度の初期値（単純弟）

| 項目 | 値 |
|---|---|
| レンジ / 初期値 | 0〜100 / **50** |
| 下限（床） | **20**（デススパイラル対策） |
| 表示 | 5段階ラベル・数値マスク |
| 支持時 | **+2〜3** |
| 却下時 | **−5前後** × 却下カードの美的スコア係数 |

1周の受動介入が約6回なので、**全却下で−30＝床に到達、全支持で+15程度**。下降が上昇の倍速く、1周で床まで落ちうる。厳しすぎるかはArtifact試作で体感確認する。

## 4. 想定される完成デッキ（介入なしの場合）

### 欠損の判定基準（15枚デッキ）

| 判定 | 条件 | 実測発生率 |
|---|---|---|
| 除去不足 | 除去2枚未満 | **83%** |
| 耐久不足 | 守護2枚未満 | **53%** |
| 重量渋滞 | 6コスト以上3枚以上 | **41%** |
| 低コスト不足 | 2コスト以下4枚未満 | **23%** |

※盤面残存力（紙耐久）は判定から除外。対戦エンジン未実装のため、体力の低さが実際に勝敗へ与える影響を測定できず、調整の根拠がないため。対戦実装後に再検討する。

### 実測結果（2000周・介入なし）

- モンスター約14枚／スペル1〜2枚、平均コスト3.59
- 守護1.49枚、除去0.76枚、2コスト以下4.6枚、6コスト以上2.2枚
- 一目惚れ発火 平均2.8回、受動介入 平均6回
- 1周あたりの欠損数 平均2.03個

**除去不足83%は仕様として意図的に残す固定欠損である。** ①モンスター優先がある限り単純弟は除去スペルをほぼ取れない。周ごとに変動しないため診断対象にはならないが、「除去はアドバイスで注文するもの」という役割が固定され、注文しなかった周は明確に負けるという因果がはっきりする。ここをカバーする行為自体にゲーム性を置く設計判断。

**診断対象となるのは耐久（53%）と重量（41%）の2軸。** 目標帯（40〜60%）に入っており、「今回は守護があるが重い」「守護がなく軽い」という周ごとの差が実際に発生する。低コスト不足23%は、アグロとしてカーブが自然に整った結果であり想定通り。

## 5. 対戦エンジン仕様

### フォーマット：シャドウバース準拠

対戦ルールは独自開発しない。独自性は対戦部分になく、枯れたフォーマットを借りて発明コストをゼロにする。

- ライフ20 / PP毎ターン+1・上限10 / 場5枠 / リーダーへの直接攻撃あり
- 速攻・守護は既存挙動を踏襲。残り5語も既存語彙で定義済み
- **手札誘発なし・割り込みなし。** 実装難易度以前に、それを完璧に使いこなす子供が不自然だから

### 子供AIの思考

ハースストーン系は「顔を殴るかトレードするか」の一次元判断が体験の大半を占める。**キャラの戦闘中の偏りはこのバイアス一個で表現する**（単純弟＝顔優先、聡明弟＝トレード優先、気弱妹＝保守的）。AIは全キャラ共通で1本、係数のみ差し替え（原則2）。

### 帰責可視化：発火語彙をキャラごとに絞る

介入由来でデッキに入ったカードには**介入フラグ**を付与し、対戦画面上でマーキングする。そのカードが実効的な仕事をした瞬間に、子供の台詞を**1試合1カードにつき1度だけ**発火させる。

**発火語彙はキャラごとに異なる。** 7語すべてを網羅しない。喋りすぎはプレイヤーへの忖度が透けて違和感を生むため、絞ることで沈黙の意味が濃くなる。

**設計上の意味：同じ盤面を見ていても、何を「仕事」と認識するかがキャラで違う。** 単純弟は守護が攻撃を吸ったことに気づかない——地味な仕事はアグロ思考の子供の視野に入らない。逆に気弱妹は守ってくれたことに気づく。原則2（個性は賢さではなく偏り）の対戦パートへの延長であり、実装は`data/children/`の発火語彙リストのみで、エンジンは共通。

**単純弟の発火語彙（プロトタイプ確定）：ダメージ / 破壊 / 強化 の3語のみ**

プレイヤーの介入先は除去と強化に偏るため、実際に介入した札が鳴る確率が高い。1試合の発火は0〜2回程度に収まる想定。

| 語 | 「仕事をした」の判定 |
|---|---|
| ダメージ | 敵モンスターを破壊した、または相手リーダーのライフを削った。敵不在での空振りは発火しない |
| 破壊 | 対象を除去した。対象不在の不発は発火しない |
| 強化 | **反実仮想判定あり。** 強化がなければ届かなかった結果を生んだ場合のみ（強化前の打点で同じ結果になるなら発火しない） |

**単純弟では発火しない：** 守護 / 速攻 / ドロー / 復活 / バニラ（キーワードなし）

- ドローは引けば必ず成功するため、入れれば必ず鳴る＝安っぽくなる
- 守護は気弱妹の発火語彙として将来採用する
- バニラは判定基準が曖昧で、ほぼ全モンスターがいずれ鳴るため沈黙の設計が壊れる

**トドメ枠（全キャラ共通・7語判定とは独立）**

最後の一撃が介入フラグ持ちのカードだった場合、語彙を問わず発火する。決着の瞬間は誰でも認識するため「認識の解像度」の理屈に反さず、ホビーアニメとして決着で叫ばないのは不自然。

**「初めて場に出た介入カード」での発火は採用しない。** 出した瞬間に鳴らすと腐ったカードでも鳴り、成否の区別がつかなくなる。

**仕事をしなかった場合、台詞は発生しない。** 一度も鳴らない試合は、その周の介入が機能しなかったということ。**沈黙が失敗の表現である。**

**試合後の数値集計は行わない（原則4）。** 「介入寄与7点」のような採点表はシステムが成否を評価している状態であり、判断をプレイヤーに残す方針に反する。またトーン（賑やかな楽しさ）とも噛み合わない。

### 対戦相手の台詞

**相手も喋る。** 平成ホビーアニメで対戦相手が黙っているのは不自然であり、賑やかさの担保になる。

加えて機能面の効果が大きい。**相手の煽り台詞が盤面の解説になる。** 「そんな貧弱なモンスターで俺の壁を抜けるつもりか！」は実質的に「あなたのデッキは打点不足です」という診断結果の提示であり、**原則4を破らずにプレイヤーへ欠損を気づかせる経路**になる。数値パネルより遥かにトーンに合う。

将来ギミックデッキの幹部を実装する際、台詞が相手の戦術を予告する形になるため拡張性もある。

## 7. 保留事項（低信頼の症状群）

信頼度が低い状態の表現として検討したが、プロトタイプでは実装しない。現状の試作で「6回の裁定が退屈でないか」「下降が厳しすぎないか」の一次検証を先に行い、その結果に応じて処方を選ぶ。

- **拒否：** 却下時のみ発生。プレイヤーが弟の希望に逆らった時だけ判定し、拒否されても信頼度は下がらない（むしろ微増＝デススパイラルへの自然な歯止め）。不機嫌側の下2段でのみ発生。アドバイス（定点フェーズ）は拒否対象外とする
- **聞くのをやめる：** 低信頼時、「聞こうとしたけどやめた」を明示して自動決定に移る。スペル2枚提示のような**最も価値の高い介入機会**が独断で潰れる。頻度低下を可視化する手段
- **連続却下の加速：** 連続して却下するたび下降幅が加速（−5、−7、−10…）、支持を1回挟めばリセット。「合計何回却下できるか」から「どこで折れるか」へ判断の質が変わる
- **信頼度とテンションの二値化：** 根本的な信頼は揺るがないが連続却下で拗ねる、というモデル。プレイヤーからは合成された1状態にしか見えないため現状は過剰。ただし**聡明弟の表現には直結する**（信頼はあるが頼るのを嫌がる＝高信頼・低テンション）ため、キャラ拡張時に再検討する

## 実装状況（1ループ版時点）

本文書は単発戦プロトタイプ時点の仕様である。その後の実装で以下が変更・追加された。

- **梯子3連戦：** rush → wall → boss の順で対戦し、試合ごとにデッキビルドを行う
- **相手先出し：** 対戦相手を先に提示してからビルドに入る。相手はタイプ名とtraitのみ表示し、デッキリストは見せない
- **信頼度の持ち越し：** 信頼度は梯子を通じて持ち越し、周の開始時のみ初期値50に戻る
- **対戦相手データ：** `data/opponents.json` に外出し済み

**敗北時の進行：** 本来仕様は「負ければ終了」だが、プロトタイプでは3戦通しの検証効率を優先して意図的に無効化中。勝敗に関わらず梯子が続く。本実装時に戻す。

**信頼度の効果：** 受動介入頻度への影響は実装済み。信頼度の5段階に連動し、低い方から 25% / 40% / 50% / 60% / 70%（`data/children/tanjun.json` の `passiveInterventionRatesByTrustLevel`）。一目惚れ時の抑制と、アドバイス由来ピックの100%介入は信頼度に関わらず維持する。アドバイス解釈精度・受諾率への影響は仕様として維持するが未実装。

**第一希望の非表示：** 受動介入時、弟の第一希望を示すタグはUIに出さない。2枚は対等に提示し、弟の内心は裁定後の反応でのみ分かる。表示があると判断が「希望に乗るか逆らうか」の応答に偏り、決定表を読む遊びが立ち上がらないため（テストプレイで確認）。信頼度の変動ロジックは従来通り第一希望を支持したかで判定する。

**裁定後の反応台詞：** 受動介入を裁定した直後、`dialogue.support` / `reject` を画面上部の固定位置に表示する（答え合わせ）。確認ステップは挟まず、次のピック提示に重ねて出したまま残し、次の操作（カード選択・裁定・アドバイス選択）で消える。支持は青・却下は赤で見分けるが、信頼度の増減量は出さない。アドバイス由来のピックは受動介入ではないため対象外。
