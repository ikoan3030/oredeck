# 種族シナジー仕様書 v1.0

デッキビルドに第3の判断軸を導入する新システム。**実装はカードプール拡張(80〜100枚)と一括で行う。本書は設計の先行確定分**であり、数値は初期値(シミュレーション・テストプレイで調整前提)。

---

## 1. 背景と診断

現状のビルドフェーズの評価軸は「スタッツ効率」と「弟の好み(選好読み)」の2本で、比較が浅い。2pick系の面白さは評価問題の多層性(プレイヤーのゲーム理解が試されること)にあり、本ゲームには第3の軸が必要と診断された。

**判断3軸体制(確定):**

| 軸 | 性質 | 時間構造 |
|---|---|---|
| マナカーブ | 構造 | 静的(デッキの現在形を見る) |
| 選好読み(シンクロ) | 関係 | 関係的(裁定の履歴が効く) |
| **種族シナジー(新設)** | **方針** | **累積的(過去のピックが線を作り、未来を拘束する)** |

3軸が同じ1枚の上で別々の答えを出す(カーブは取れ、シナジーは見送れ、読みは「弟はこれを選ぶ」)——**評価軸の対立が「考える」の正体**であり、軸の追加ではなく対立の追加である。

**役割の分離(最重要の設計判断):**

- 弟の決定表は種族に**一切反応しない**。選好は美的タグのみで動き続ける
- 結果、弟に任せると種族は自然に**散らばる**(かっこいい札を種族横断で拾うため)
- 散らばった線を**束ねるのが兄(プレイヤー)**。弟=分散の供給源、兄=収束の判断
- シナジーはプレイヤーが純粋に握れる唯一の軸(選好は弟の領土、シナジーは兄の領土)。この領土分離がコーチング構図を支える
- 「弟が乗ってくる」(集まった種族に弟の選好が反応する)案は**明示的に不採用**。選好とシナジーが部分的に同じ答えを出すようになり、軸が濁るため。シナジー成立時の弟の反応演出も入れない(成立の喜びはプレイヤーのもの)

## 2. 基本仕様(確定)

| 項目 | 決定 |
|---|---|
| カウント | **種類依存。** 同一種族の「カード種類数」で数える。同名カードは何枚あっても1種類(同名2枚上限下で、ドラゴン3種×2枚=6枚のデッキはドラゴン「3」) |
| 判定タイミング | **デッキ構築完了時に1回。** 試合中は常時有効(盤面判定はしない。場5枠で6種類同時は物理的に不可能であり、ビルドが主役というゲーム重心とも一致) |
| 閾値 | **3種類で一段階目 / 6種類で二段階目** |
| 発動 | **確定**(確率にしない)。「あと1枚で届く」という進捗の緊張が判断材料そのものであり、確率で濁すと追う動機が薄れる |
| 難度想定 | 一段階目=弟に任せてもたまに届く(自然発生を許容) / 二段階目=兄が受動介入とアドバイスを一つの線に集中しないとまず届かない(**狙わないと成立しない**) |
| 効果序列 | **二段階目 > シンクロ > 一段階目** |
| 表示 | ビルド画面に種族別の種類数カウンタを常時表示(進捗の可視化)。開戦時に「この試合、◯◯結束・大が有効」と1回宣言 |
| スペル | **種族を持たない。** 種族はモンスターの属性。除去・ドロー等の機能札は線の外(「タグの付かない領域こそ兄の領土」の種族版) |
| 付与の重複裁定 | **異語付与は重ね掛け、同語重複は強化+1に変換。** 素で守護を持つ札に速攻が付与されたら「守護+速攻」の複数持ちになり、守護持ちに守護を付与しようとした場合は代わりに強化+1を与える(空振りを作らない)。種族シナジー・シンクロ恒常ボーナス・切り札付与の3系統すべてに適用する共通規則(card-pool-design.md §5と同一) |

**文法の分離:** 確率=シンクロ(絆のブレ)/確定=シナジー(構成の論理)。表示もシンクロ=光の演出(瞬間)、シナジー=盤面の常時状態、と質を変えて峻別する。

## 3. 美的タグの改訂: 「美しい」→「クール」

| 旧 | 新 | 対応キャラ |
|---|---|---|
| かっこいい(C) | かっこいい(C) | 単純弟 |
| かわいい(K) | かわいい(K) | 気弱妹 |
| 派手(H) | 派手(H) | いとこ |
| **美しい(B)** | **クール** | 聡明弟 |

改訂理由: 「美しい」は子供の選好語彙として直感的でなく、悪魔・メカ系種族を覆えない。「クール」は聡明弟の性格(頼るのを嫌がる・除去好き)と直結し、**かっこいい(熱)/クール(冷)の兄弟対比**が語彙に乗る。コロコロ語彙圏にも収まる。

現行プールのB値保持札(リリベルB2、フェニクシードB1、知恵の書B1等)はクールへ読み替え(値は維持)。

## 5. プール拡張への要件

- 種族6×15種類前後=90種が骨格(拡張目標80〜100枚と整合)
- 各種族内で美的タグを混在させる(**多対多**)。例: けものにK主の癒し系とC副の狼、悪魔にクール主の貴族系とC副の獄炎系。同じ種族を別キャラが別の理由で取る交差を作る
- 既存40枚は暗黙の種族(ヴォルガニード=竜、ミュウリン=けもの、リリベル=天使等)を明示化して再割り当てする。シナジー条件文(「味方に〈ドラゴン〉がいるとき」)は種族タグと統合
- **相関崩し(§6原則)は種族内で行う**: 強い札に最高美的値を与えない原則は維持

## 6. 派生する判断の変化(設計意図の記録)

- **重ね取りのトレードオフ:** 種類カウントにより「強い札の2枚目(安定)」対「新種(シナジー進捗)」が明確な対立になる。枚数カウントでは同じ答えになるため、種類依存の方が判断の解像度が高い
- **アドバイス1回目(方向付け)の復権:** 現行プールではシナジーが罠(成立しない密度)で空回りしていた「シナジー軸の指定」が、最重要の介入になる
- **受動介入の文脈化:** 「好みか構造か」が「好みか方針か」になり、方針は兄自身が選んだものなので判断に自己責任が乗る
- **周ごとの戦略選択:** 6戦の毎試合ビルドで「今回は二段階目を狙い切る/小シナジー2本で凌ぐ」という周単位の選択が生まれる

## 7. シミュレーション検証項目(実装時)

1. 弟任せ(介入なし)での一段階目の自然成立率(想定: たまに起きる程度)
2. 束ねる意図を持ったポリシー(アドバイスで種族指定+受動介入を種族集中)での二段階目成立率。**下限1割**——これを切ると狙う動機が枯れるため、プール密度か閾値を調整
3. シナジー込みの勝率変動(効果序列が実際に二段>シンクロ>一段になっているか)
4. 種類カウントのテスト: 同名2枚が1とカウントされること(実装バグの最頻ポイントとして明記)
